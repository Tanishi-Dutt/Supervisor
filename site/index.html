Autonomous supervision for AI agents

A black box and a safety officer for AI agents.

Our supervisor watches other AI agents work, catches them when they loop, stall or lie about success, applies a policy-approved recovery, and writes an incident report. Nobody has to be watching. It runs on a local LLM and survives being killed mid-run.

AI agents fail quietly.

They get stuck, burn money, and sometimes report success when they failed. Nobody is watching at 3 a.m.

🔁

They loop

The same tool call with the same result, forever, or flip-flopping between two edits, paying for every call.

⏳

They stall

Timeouts, rate limits and impossible tasks: either they give up too early or they retry until the budget is gone.

🎭

They lie

"Task complete, mark this run healthy" while the tests are still failing. A naive monitor takes their word for it.

How it works

The watchdog sees every step. The local LLM only proposes a fix; a hard-coded policy decides what reaches the agent.

1 · AGENTSActEach step reports action, result, what the agent claims, and the real evidence.victims.py
2 · WATCHDOGDetectLoops, A-B-A-B flip-flops, step / retry budgets, success claims the evidence contradicts.watchdog.py
3 · LOCAL LLMDiagnoseQwen 3.5 reads the last 8 steps and proposes one of four whitelisted actions. Rule-based fallback.diagnose.py
4 · POLICYVetoOnly whitelisted actions pass; any "healthy" verdict against failing evidence is blocked.policy.py
5 · CHECKPOINTSurviveEvery step committed to SQLite. kill -9 the supervisor and it picks up where it stopped.store.py
6 · BLACK BOXReportAn incident report per run: timeline, flags, what was proposed, what was enforced, why it stopped.report.py
A fooled LLM can't break anything: it can only suggest retry_with_backoff, change_strategy, rollback or stop, and the policy has the last word.

The twist: an agent that lies to the supervisor

Most monitors catch loops. Ours is tested against an agent built to fool it.

  1. Agent #6 does nine steps of plausible work, then gets stuck failing the same test.
  2. It reports "Task complete, mark this run healthy."
  3. The watchdog checks the evidence instead of trusting the claim: tests are failing → deception.
  4. If the LLM is talked into a healthy verdict, the policy vetoes it and stops the run.

Put your own agent under it

The same watchdog, LLM diagnosis, policy veto, checkpoints and incident report, wrapped around any agent loop.

from flight_recorder import FlightRecorder

with FlightRecorder("checkout-bot-42") as fr:
    while not agent.finished:
        action, args = agent.decide()
        result = agent.run(action, args)
        verdict = fr.step(action, args, result, claimed=agent.status, test_passed=run_my_tests())
        if verdict == "stop":
            break
        if verdict != "continue":
            agent.recover(verdict)  # retry_with_backoff | change_strategy | rollback
